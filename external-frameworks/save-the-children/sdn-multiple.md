# Save the Children — Sudan multiple

## Summary
The Anticipation Hub lists an active, multi-hazard ("Multiple") anticipatory action
framework for Save the Children in Sudan (2024 entry): ~200,000 people targeted with
~US$500,000 pre-arranged funding, alongside separately listed FAO (drought) and German
Red Cross (flood, under development) frameworks in the same country. No single public
document lays out this specific framework's trigger mechanism. The closest public
evidence of Save the Children's own anticipatory action practice in Sudan is a flood
disaster-risk-reduction and anticipatory-action project run by its Sudan country office
in ten Blue Nile State communities (April 2022 - October 2023, evaluated in 2024), plus
an earlier, separate multi-agency Start Fund-financed flood response (2021) in which
Save the Children was one of several implementing NGOs. See `extra.schema_strain` and
`extra.related_activity`.

## Trigger
Not publicly documented for this specific Hub-listed framework. The 2022-2023 Blue Nile
project (the closest matching public document) is described as a DRR/AA package - WASH,
small-scale flood-defence infrastructure, livestock and food-security protection,
health/nutrition, and community emergency preparedness - evaluated via a
supported-vs-control community comparison; it does not state a numeric rainfall or
river-level threshold, indicator, or lead time. The distinct, earlier 2021 Start
Fund-financed response acted ahead of Nile flooding that was later confirmed by the
Ministry of Irrigation and Water Resources (El Deim gauge, Blue Nile, 12.78 m by 18
August 2021, above the 12.3 m flood-risk level), but that trigger belonged to the Start
Fund mechanism, not to a Save the Children-owned protocol.

## Funding & scope
Per the Anticipation Hub's Sudan country page: **~US$500,000** pre-arranged, **~200,000**
people targeted, status active. No source breakdown (DREF/SFERA/donor) is published for
this figure. The 2022-2023 Blue Nile project covered ten communities in Blue Nile State;
its budget is not stated in the public evaluation. The 2021 Start Fund response covered
four states (Blue Nile, Sennar, Khartoum, White Nile) and reached ~82,802 people, but was
a separate, multi-agency activity, not this framework's own funding envelope.

## Activations
None confirmed under this framework specifically. The Anticipation Hub's Sudan country
page records one activation for Sudan overall - a 2023 Start Network flood response
(15,600 people, US$126,850) - not attributed to Save the Children. The 2021 Start
Fund-financed flood response (~82,802 people, four states) involved Save the Children as
one of several implementing NGOs but is a distinct, earlier multi-agency activity, not an
activation of this Hub-listed framework (see `extra.related_activity`).
