# Save the Children — Nepal landslide

## Summary
The Anticipation Hub's global inventory lists an active Save the Children anticipatory
action framework for landslide in Nepal since 2023, with US$16,000 pre-arranged and 1,000
people targeted. No public framework document, trigger detail, or activation record for this
specific instrument could be located — the figures above come from the Hub inventory alone.
Save the Children Nepal is known to run single-hazard Early Action Protocols for other
hazards (flood, cold wave) in Banke district, and is separately a partner in an EU-funded
landslide forecast-based-action pilot in Sindhupalchok district (see `extra.related_context`),
but neither of these confirms the specifics of this Hub-listed landslide record.

## Trigger
Not sourced. No public document describing the indicator, threshold, or lead time for this
framework was found (see `extra.schema_strain`).

## Funding & scope
US$16,000 pre-arranged, targeting an estimated 1,000 people, per the Anticipation Hub
inventory — the sole source for these figures. No funding-source breakdown (e.g. Save the
Children's own emergency fund vs. a donor) or specific municipality/district coverage is
available in public sources.

## Activations
None known. No activation record for this framework was found in Anticipation Hub, ReliefWeb,
or Save the Children reporting.
