# Save the Children — Nepal cold wave

## Summary
Save the Children International and Save the Children Nepal, working with local partner
Social Development Forum (SDF), run a Cold Wave Early Action Protocol for Rapti Sonari
(Raptisonari) and Narainapur Rural Municipalities in Banke District, Lumbini Province —
the same Terai lowland district where Save the Children and IFRC/NRCS also run separate
flood early-action instruments. Published in 2022 (author Hemanta Dangal), the EAP covers
cold-wave/heavy-snowfall risk analysis, thresholds and triggers, agreed early actions and
beneficiaries, costs, and monitoring, pre-arranging roughly US$38,000 for about 13,200
people per the Anticipation Hub's global-map inventory (a more recent Hub country-page
listing gives a larger US$73,000 / 15,200 figure for the same framework — see
`extra.funding_note`). This is Save the Children's own instrument, unrelated to any
OCHA/CERF collective framework.

## Trigger
A forecast-based trigger for cold wave/heavy snowfall conditions in the two Banke
municipalities. Public sources (the Save the Children Resource Centre listing, DPNet
Nepal, the Anticipation Hub) confirm that the EAP document itself specifies a cold-wave
risk analysis and defined thresholds/triggers, but the exact meteorological indicator,
numeric threshold, and lead time are not stated in any accessible secondary source, and
the primary PDF could not be text-extracted by available tooling (image-based content
stream) — see `extra.schema_strain`.

## Funding & scope
US$38,000 pre-arranged for an estimated 13,200 people, per the Anticipation Hub
global-map inventory record for this framework. The Hub's Nepal country overview page
currently lists a larger figure (US$73,000 / 15,200 people) for the same "Cold
wave/heavy snowfall — Save the Children" entry; it is not confirmed whether this is an
updated/later revision or a different accounting basis (`extra.funding_note`). No
specific funding facility (DREF/SFERA-equivalent) was identified in public sources —
Save the Children lists itself as both implementing and (with SDF) delivery partner. The
same two municipalities are also covered by Save the Children's own flood
(US$88,000/3,000 people) and Start Network's landslide/mudslide (US$43,292/1,500 people,
a different org) frameworks, per the same Hub country page — distinct hazard-specific
instruments, not part of this cold-wave EAP.

## Activations
None confirmed in accessible public sources. The framework appears in the Anticipation
Hub's inventory for both 2023 and 2024 (`extra.hub_captions`), which reflects it being
listed as an active framework in those years' snapshots rather than a confirmed trigger
event. A 2023 ResearchGate-listed "summary report" for this same Raptisonari cold-wave
programme may document a pilot activation or test run, but its content was not
accessible (403) — worth a follow-up check.
