# Save the Children — Malawi drought

## Summary
The Anticipation Hub's global map lists a "Save the Children" drought framework for
Malawi (2024 inventory entry), but no independent, Save the Children-owned framework
document, trigger design, funding envelope or target population was found in any public
source checked. The Hub's own Malawi country page shows this entry with **0 people
targeted, $0 budget, and no linked document** — distinct from, and much thinner than,
the separately listed OCHA framework (377,115 people / $7M) and FAO framework (41,450
people / $1M) for the same hazard on the same page.

## Trigger
Not documented in any public source found. No Malawi-specific Save the Children
trigger, indicator, threshold or lead time could be located — see `extra.schema_strain`.

## Funding & scope
Not documented. The Hub's Malawi country page lists $0 budget / 0 people targeted for
this entry, which reads as an unenriched placeholder rather than an actual zero-funded
programme. Save the Children International is named in FAO's regional reporting as one
of several organisations supporting drought anticipatory action across Zimbabwe,
Madagascar and Malawi, but no Malawi-specific, Save the Children-attributable funding
figure is given anywhere found.

## Activations
None documented. No Save the Children-specific Malawi drought activation was found in
public reporting.
