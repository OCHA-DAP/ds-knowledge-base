# START — Bangladesh tropical cyclone

## Summary
Start Network's Bangladesh cyclone anticipatory action runs through **Start Ready**, its
pooled, parametric disaster-risk-financing facility, layered with **Start Fund Anticipatory
Alerts**. Start Ready pre-positions funds across a multi-country, multi-hazard risk pool and
disburses automatically to Start Bangladesh member NGOs when its (undisclosed) parametric
model fires — for Cyclone Remal (2024) this meant funds moving to nine member agencies in
four high-risk coastal districts about 48 hours before landfall. Start Network is also a
funding contributor to the separate OCHA/CERF-coordinated Bangladesh cyclone framework (see
Coordination below).

## Trigger
Public sources describe the *outcome* rather than the mechanics: Start Ready's cyclone
window triggered automatically on forecast track/intensity roughly 48 hours ahead of Cyclone
Remal's landfall (night of 26 May 2024), before the national BMD signal system or the
OCHA/CERF collective framework's multi-model trigger fired. No source found publishes the
underlying wind-speed/category threshold or forecast model(s) used by the parametric
mechanism. A separate, alert-based Start Fund Anticipatory Alerts window can also trigger
independently.

## Funding & scope
Anticipation Hub inventory records ~US$766,284 pre-arranged and 20,000 people targeted for
this framework. For the one confirmed activation (Remal), Start Ready released GBP 180,000
(~US$228,000) reaching an estimated 30,000 people across 36 unions in Satkhira, Khulna,
Patuakhali and Barguna districts (11 upazillas), delivered by nine Start Bangladesh member
NGOs — early-warning messaging, shelter/WASH preparedness, evacuation support, cash and
livestock-feed assistance. Start Fund Rapid Response separately allocated GBP 800,000
post-landfall (not anticipatory).

## Activations
- **24 May 2024, Cyclone Remal** — the first event ever to trigger Start Ready, Start Fund
  Anticipatory Alerts, and Start Fund Rapid Response together for the same crisis. Start
  Ready's ~48h-lead trigger released £180,000 for anticipatory action reaching ~30,000
  people; a separate £800,000 Rapid Response allocation followed after landfall.
- No other real AA activation is documented in the sources reviewed. The Hub's 2022 listing
  names only "Start Network" itself with no corroborating activation report — not counted
  as a confirmed activation here.

## Coordination
Start Network (via Start Ready) is also a named co-funder of the **OCHA/CERF collective**
Bangladesh cyclone framework — US$1,775,000 in the 2025 framework's financing table (see
`frameworks/bgd-cyclone/2025-04-25.md`). That collective framework's own trigger (≥2 of 5
forecast models agreeing on 118 km/h at union level) has never fired — including during
Remal, when CERF instead fast-tracked a post-landfall rapid-response allocation. Start
Ready's own parametric trigger is independent of that CERF trigger and did fire for Remal.
This page therefore documents Start Network's own, separately-triggered mechanism — not a
restatement of the OCHA collective page — while noting the funding overlap.
