# START — Zimbabwe drought

## Summary
Start Network's anticipatory action work on drought in Zimbabwe is not a single framework
but a portfolio of related instruments run through its members. Since January 2022, Start
Network has held an **ARC Replica** parametric insurance policy (layered on the Government
of Zimbabwe's own African Risk Capacity cover), which pays out automatically when ARC's
rainfall-driven drought index crosses a threshold. Separately, Start Network member NGOs
have run **forecast-based-action Early Action Protocols**: a Welthungerhilfe-led EAP
(2020-2022, with Action Against Hunger and Trócaire) in three pilot districts, and a newer
**"Start Ready" drought programme** (Christian Aid, Save the Children, World Vision
International) first activated in November 2024. All three read as "Drought (Start
Network)" on the Anticipation Hub's Zimbabwe map, which is why they share one page here.

## Trigger
- **ARC Replica (insurance):** ARC's **Africa RiskView** platform converts satellite
  rainfall data into a **Water Requirements Satisfaction Index (WRSI)** — a crop-water
  drought index — combined with population-vulnerability data to estimate drought-affected
  populations and response costs for the Oct-Apr agricultural season; the policy pays out
  automatically once modelled losses cross a pre-agreed threshold, ahead of an on-the-ground
  crisis. No public source gives the specific numeric threshold for Zimbabwe's policy.
- **Welthungerhilfe-led EAP (2020-2022):** described only as using "various climatological
  and humanitarian forecast data" to anticipate drought events with roughly a 10-year
  average return period; specific indicator values and lead time were not found in public
  sources.
- **Start Ready programme (from 2024):** triggered by seasonal/climatological forecasts
  ahead of the rainy season; no public numeric threshold or lead-time figure was found.

## Funding & scope
- **ARC Replica:** Start Network paid a ~US$2.5M premium (announced January 2022) for
  cover protecting up to ~800,000 people; named NGO partners for implementation if the
  policy pays out are ActionAid Zimbabwe, Action Against Hunger, CAFOD, Catholic Relief
  Services, GOAL, Plan International, Tearfund, Trócaire and World Vision Zimbabwe.
- **Welthungerhilfe-led EAP:** covered Chimanimani, Chivi and Matobo districts; no public
  budget figure found. Implementation funding, once triggered, comes from Start Network's
  NGO-specific financing facility (Start Ready), with the German Federal Foreign Office
  supporting development of the mechanism.
- **Start Ready programme (2024- ):** run by Christian Aid, Save the Children and World
  Vision International across 3 districts (names not found in public sources); no public
  budget figure found.
- The Anticipation Hub's Zimbabwe country page currently lists two separate **active**
  Start Network drought entries — US$600,000/53,000 people and US$1,604,626/23,681 people —
  which likely correspond to the EAP/Start Ready programmes above, but public sources do
  not confirm which figure belongs to which. See `extra.funding_note`.

## Activations
- **May 2022 — "RP1 Zimbabwe Drought."** Start Ready disbursed a pre-positioned £471,271
  (~US$570,000) to Bulilima, Binga, Bikita, Buhera and Mberengwa districts as drought
  indicators reached an alarm threshold; tied to the newly-purchased ARC Replica cover.
- **2022 — "FbF Zimbabwe Drought 2022."** The Welthungerhilfe/Action Against
  Hunger/Trócaire EAP triggered in Chimanimani, Chivi and Matobo districts; Start Network
  released implementation funding to all three EAP custodians (Tsuro Trust, Nutrition
  Action Zimbabwe, Caritas Bulawayo as local partners).
- **5 July 2024 — ARC Pool VIII payout.** The 2023/24 El Niño season triggered a combined
  US$32M ARC payout (Government of Zimbabwe US$16.8M, WFP US$6.1M, Start Network US$8.9M)
  for an estimated 509,000 households across 27 districts; Start Network's US$8.9M funds
  its NGO members' response under the ARC Replica arrangement.
- **November 2024 — first Start Ready drought-programme activation.** Christian Aid, Save
  the Children and World Vision International implemented anticipatory action across 3
  districts: early-maturity sorghum/millet seeds, fodder seeds (velvet bean, lablab),
  livestock veterinary/dipping kits, and community preparedness training. An independent
  programme evaluation ran March-August 2025.

No trigger-not-met / near-miss events were found in public reporting.
