# World Vision International — Myanmar tropical cyclone

## Summary
World Vision Myanmar (WVIM) operates a cyclone Anticipatory Action Protocol, developed
with World Vision's East Asia/South Asia Pacific regional office, targeting the
high-risk Ayeyarwady Delta and Rakhine State — with a stated intent to expand to other
Area Programmes. The Anticipation Hub has listed it as an active framework since 2023
(US$72,000 pre-arranged, ~17,262 people targeted). It sits alongside similar
World Vision-supported AA protocol pilots in five other Asia-Pacific field offices
(Bangladesh, Indonesia, Mongolia, Philippines, Sri Lanka); no dedicated public
framework document, trigger design, or funding breakdown for the Myanmar protocol was
located.

## Trigger
Not published. World Vision's own description of the Myanmar program states only that
it is an "Anticipatory Action Protocol" covering the Ayeyarwady Delta and Rakhine
State, including a simulation-exercise component; it does not disclose the
meteorological indicator, threshold, or lead time used to trigger action.

## Funding & scope
US$72,000 pre-arranged funding, targeting an estimated 17,262 people (Anticipation Hub
inventory, listed since 2023). No source-level funding breakdown is public. The
best-documented comparable World Vision AA project in the same regional program —
Bangladesh's cyclone AA project (Sept 2022–Nov 2023) — was funded by Aktion
Deutschland Hilft (ADH Germany); it is not confirmed whether the same donor funds the
Myanmar protocol.

## Activations
None known. Cyclone Mocha (May 2023) made landfall in the Ayeyarwady/Rakhine area this
protocol targets and triggered a large multi-agency humanitarian response, but no
public source documents a World Vision anticipatory (pre-landfall) activation under
this protocol for Mocha or any other storm.
