# Australian NGO Cooperation Program — Indonesia tropical cyclone

## Summary
An anticipatory action (AA) framework for tropical cyclones in Indonesia, funded through
the Australian NGO Cooperation Program (ANCP) — the Australian Government's core
funding partnership with accredited Australian NGOs — and implemented by Wahana Visi
Indonesia (World Vision's Indonesian national office). Listed in the Anticipation Hub's
global inventory since 2023, with USD 100,000 pre-arranged and 15,000 people targeted.
No dedicated public protocol document was located; trigger mechanics, exact geography,
and activation history are not confirmed in public sources.

## Trigger
Not publicly documented. The Anticipation Hub inventory records the hazard only as
"Cyclone / hurricane / tropical storm / typhoon" with no indicator, threshold, or lead
time specified. Wahana Visi Indonesia has separately reported running Tropical Cyclone
Disaster Anticipation Action Protocol workshops with the Government of Alor Regency,
East Nusa Tenggara, as part of its broader multi-hazard "ANTICIPATION" project — this
may be the same on-the-ground protocol, but no source ties the two together explicitly
or states the trigger criteria used.

## Funding & scope
USD 100,000 pre-arranged funding via ANCP, targeting an estimated 15,000 people, per the
Anticipation Hub's global-map inventory (framework listed since 2023). No breakdown by
funding tranche, target district, or coverage area is published. ANCP itself funds
several distinct, unrelated AA trials across Indonesia (e.g. a separate flood trial in
Lombok run by Penabulu Foundation/Yayasan KONSEPSI via Oxfam Australia), so ANCP should
be read as a funding channel rather than a single named program design.

## Activations
None known. No activation record for this framework was found in public sources
(Wahana Visi Indonesia's own reporting, ReliefWeb, or the Anticipation Hub).
