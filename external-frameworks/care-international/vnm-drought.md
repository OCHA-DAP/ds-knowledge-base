# CARE International — Vietnam drought

## Summary
The Anticipation Hub's inventory lists an active drought/dry-spell anticipatory-action
framework attributed to CARE International in Vietnam, implemented jointly with CARE in
Vietnam, Plan International and World Vision International: $623,000 in pre-arranged
funding targeting 5,272 people. No independently-published CARE framework document,
trigger report or activation record turned up in public search — the Hub's summary
figures are the only public detail available. The same three NGOs (CARE, Plan
International, World Vision International) are named elsewhere as consortium partners on
an FAO/DG-ECHO anticipatory-action partnership covering Vietnam (among five Southeast
Asian countries), but no source confirms whether this drought framework is part of that
FAO/ECHO arrangement or a separate CARE-led one.

## Trigger
Not publicly documented. No CARE, Plan International or World Vision publication
describing an indicator, threshold or lead time for this framework was found. For
context, Vietnam's Ministry-run Combined Drought Index (also used by FAO's own, larger
and separately-listed Vietnam drought framework) is the region's standard drought
anticipatory-action indicator in Southeast Asia, but no source ties CARE's framework to
that specific index.

## Funding & scope
$623,000 pre-arranged funding for 5,272 targeted people, per the Anticipation Hub's
global-map inventory and Vietnam country page (funding source/channel and target
province(s) not stated). This is separate from two other drought-tagged Hub entries for
Vietnam: FAO's own framework ($2,038,627 / 68,000 people) and a smaller ECHO-listed
framework ($19,075 / 626 people). CARE International also holds a distinct, separately
Hub-listed flood framework in Vietnam (`external-frameworks/care-international/vnm-flood.md`).

## Activations
None known. No activation of this specific CARE-attributed drought framework was found in
public reporting.
